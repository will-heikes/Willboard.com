# Awards nominee clips

Video clips for "And the nominees are" on the awards pages. Name each one `Artist - Song.mp4`, using the
lead act (or the full credit) and the song title as the site spells them, for example
`Flatland Cavalry - A Life Where We Work Out.mp4`. Leave out characters Windows won't allow in a file
name (`\ / : * ? " < > |`). About 8 seconds each; a clip plays in place of the song's 30-second preview.
